# Scene Classification : Gunung, Pantai, Gurun, dan Kota

Proyek ini merupakan implementasi model klasifikasi gambar menggunakan Convolutional Neural Network (CNN) untuk mengklasifikasikan gambar ke dalam 4 kategori:
- Gunung (`mountain`)
- Pantai (`beach`)
- Gurun (`desert`)
- Kota (`city`)
